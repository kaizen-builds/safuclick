      How it works.

      Kane does the clicking. SafuClick reads the evidence.

      1

      You paste

      • A link from a DM, a reply or an ad.
      • Nothing touches your wallet.
      2

      Kane visits

      • kane-cli run opens it in headless Chrome.
      • On the gym it drives a swap with a mock wallet. On real sites it only observes.
      3

      You get a verdict

      • Trap flagged with reasons and evidence, or No known traps found.
      • Plus a SafuCard to warn your group.
      Lookalike / brand-impersonating domainRULE · ANY SITE
      Seed / recovery / “secret words” promptRULE + KANE · ANY SITE
      Connect Wallet on an unknown domainSIGNAL ONLY
      Unlimited / oversized approval, poisoned spenderGYM · MOCK WALLET
      Cloaking (bot sees blank, human sees scam)KNOWN LIMITATION

      What it doesn’t do.

      Honesty is part of the product.

      • It never says “safe”. The best result is “no known traps found” on this run.
      • It flags known patterns. A brand-new trick can slip through until the loop learns it.
      • Scam sites cloak. Some show bots a blank page. We caught aave-fi.info doing it live.
      • Wallet evidence needs the mock wallet. On real sites, Kane observes the page but doesn’t sign anything, so hidden approvals can’t be seen there.
      • Live checks are capped. Each one is a real Kane run that costs credits.
